# سير عمل RDP على Windows عبر Tailscale

> **تنبيه:** هذا المستودع يحتوي إعداد GitHub Actions واحدًا فقط، وليس تطبيقًا أو خدمة مكتملة. يغيّر سير العمل إعدادات RDP في عامل Windows، وينشئ حسابًا محليًا إداريًا، ويتيح اتصالات TCP على المنفذ 3389، ثم يحاول الانضمام إلى Tailscale وإبقاء المهمة جارية. يتضمن التنفيذ الحالي إعدادات وممارسات غير آمنة؛ **لا تشغّله كما هو**.

## محتويات المستودع

- `.github/workflows/main.yml` — سير عمل باسم `RDP` يعمل يدويًا عبر `workflow_dispatch` على عامل `windows-latest`.

لا توجد في المستودع ملفات تطبيق، وثائق تشغيل سابقة، ملفات اعتماديات، اختبارات، أو ملف ترخيص. لذلك يقتصر هذا الوصف على ما يفعله ملف سير العمل، ولا يدل على أن RDP أو Tailscale سيعملان بنجاح في كل بيئة.

## ما يفعله سير العمل

عند تشغيله يدويًا، يقوم ملف YAML بما يلي:

1. يفعّل اتصالات RDP على عامل Windows، ويغيّر إعدادات مصادقة طبقة RDP، ثم ينشئ قاعدة جدار ناري واردة لـ TCP على المنفذ `3389`.
2. ينشئ حسابًا محليًا ويضيفه إلى مجموعتي المسؤولين ومستخدمي سطح المكتب البعيد. كلمة مرور هذا الحساب ثابتة ومضمنة في المصدر، وتظهر بيانات الاتصال في سجل المهمة.
3. ينزّل مُثبّت Tailscale ويثبته، ثم يحاول تسجيل العامل باستخدام سر المستودع `TAILSCALE_AUTH_KEY`.
4. يستعلم عن عنوان Tailscale عدة مرات، ويختبر اتصال TCP إلى المنفذ `3389`، ثم يطبع معلومات الاتصال في السجل.
5. يبقي المهمة في حلقة انتظار مستمرة، مع ضبط مهلة المهمة في الملف على `3600` دقيقة. لا يظهر في الملف إجراء تنظيف تلقائي يعيد إعدادات RDP أو يحذف الحساب وقاعدة الجدار الناري عند الانتهاء.

هذه قراءة ساكنة للملف؛ لم يُشغّل سير العمل ولم تُختبر الخطوات أو التوافق مع إعدادات GitHub أو Tailscale.

يتطلب تعريف سير العمل GitHub Actions بعامل Windows، وسرًا باسم `TAILSCALE_AUTH_KEY` متاحًا لسياق المستودع. ويمكن بدء سير العمل يدويًا من واجهة GitHub Actions لأن الملف يعرّف `workflow_dispatch`.

لا تتضمن هذه الوثيقة خطوات تشغيل عملية، لأن التنفيذ الحالي يعرّض العامل واتصالات RDP لمخاطر كبيرة، ولا ينبغي تشغيله قبل مراجعة أمنية وتعديل التصميم. وجود السر المطلوب لا يجعل الإعداد آمنًا، ولا ينبغي وضع قيم الأسرار في README أو سجلات التنفيذ.

## تحذير أمني

يحتوي المصدر على كلمة مرور ثابتة لحساب ذي صلاحيات إدارية، ويطبع بيانات اتصال حساسة في سجلات المهمة. كما يعطّل إعدادات مصادقة/أمان RDP، ويفتح المنفذ `3389` دون تقييد نطاق المصدر في قاعدة الجدار الناري. الجمع بين هذه الخيارات قد يعرّض العامل والحساب والوصول البعيد للخطر. كذلك يثبّت سير العمل برنامجًا من الإنترنت دون إظهار تحقق مستقل من سلامة الملف، ويستمر في الانتظار حتى الإيقاف أو انتهاء مهلة المهمة.

لا تستخدم هذا الإعداد لحسابات أو أجهزة أو شبكات حقيقية بصورته الحالية. قبل أي استخدام، يلزم على الأقل إزالة بيانات الاعتماد الثابتة وتدوير أي اعتماد مكشوف، عدم طباعة الأسرار أو كلمات المرور، إبقاء مصادقة RDP الحديثة مفعّلة، تقييد الوصول الوارد على واجهة/شبكة Tailscale المقصودة، إضافة تنظيف وإنهاء محدودين زمنيًا، والتحقق من مصدر المُثبّت وسلامته. هذه نقاط مراجعة مطلوبة وليست ضمانًا بأن النظام يصبح آمنًا.
